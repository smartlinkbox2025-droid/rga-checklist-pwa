# نظام مالية العائلة — PWA عربي

تطبيق عربي RTL لإدارة الدفعات الواردة، رواتب أفراد العائلة، المصروفات، الإيصالات والتقارير. جميع البيانات محفوظة داخل متصفح المستخدم باستخدام IndexedDB ولا يوجد خادم خلفي أو اشتراك مدفوع.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## إنشاء نسخة الإنتاج

```bash
npm run build
```

سيتم إنشاء مجلد `dist` الجاهز للنشر.

## النشر على GitHub Pages

1. ارفع المشروع إلى مستودع GitHub.
2. شغّل `npm install` ثم `npm run build`.
3. ارفع محتويات مجلد `dist` إلى فرع `gh-pages`، أو استخدم GitHub Actions.
4. إعداد `base: './'` موجود مسبقًا لضمان عمل الملفات داخل أي اسم مستودع.

## الخصوصية والنسخ الاحتياطي

- البيانات تبقى على الجهاز والمتصفح المستخدم.
- حذف بيانات المتصفح قد يحذف السجلات، لذلك استخدم زر **تصدير نسخة JSON** دوريًا.
- النسخة الاحتياطية تشمل الإيصالات المرفوعة بصيغة Base64.

## العملة

التنسيق الافتراضي حسب `ar-SA` وبعملة الريال السعودي `SAR`، ويظهر رمز العملة بصيغة ر.س حسب إعدادات المتصفح.


## النشر على GitHub Pages

المشروع مخصص للمستودع:

`https://github.com/smartlinkbox2025-droid/family-finance`

بعد رفع محتويات المشروع إلى فرع `main`:

1. افتح **Settings > Pages**.
2. عند **Source** اختر **GitHub Actions**.
3. افتح تبويب **Actions** وتابع عملية `Deploy Family Finance PWA`.
4. بعد النجاح سيكون الرابط:

`https://smartlinkbox2025-droid.github.io/family-finance/`

## تحديثات النسخة
- أزرار تصدير PDF وExcel في أعلى جميع الصفحات.
- مبالغ إضافية مستقلة لكل فرد ولكل شهر في صفحة الرواتب، مع بيان وإجمالي.
- إضافة تفاصيل المصروفات داخل تقرير PDF.
- زر آمن لحذف جميع البيانات من الإعدادات مع تأكيد مزدوج.
- إصلاح GitHub Actions بحيث لا يعتمد على ملف package-lock.json.
