# Checklist Enterprise PWA

نسخة Enterprise مجانية تعمل بالكامل على GitHub Pages وبدون Backend.

## المزايا
- عربي/English وRTL/LTR
- Dashboard وتقارير PDF/Excel
- منشئ قوائم مخصصة
- شعار وبيانات الشركة
- نسخ احتياطي واستعادة
- GPS وتوقيع المفتش والمقاول
- سير اعتماد وحالة التقرير
- مستخدمون وصلاحيات محلية وسجل تدقيق
- PWA والعمل دون اتصال

## النشر
ارفع محتويات هذا المجلد إلى جذر مستودع GitHub ثم فعّل Pages من main / root.

## ملاحظة أمان
المستخدمون والصلاحيات محلية داخل المتصفح وليست مصادقة مركزية. للمزامنة والأمان المؤسسي الحقيقي يلزم Backend مثل Supabase/Firebase.
